# Moodia: Media for Your Mood 🎬

Moodia is a mood-based movie recommendation chatbot that personalizes entertainment discovery. Tell it how you feel, and it suggests media to match.

**[Try Moodia on Hugging Face](https://huggingface.co/spaces/Moodia/Moodia)
**[Try Moodia on Replit with integrated front-end](https://moodia--jasnoorchimni.replit.app/index.html)

## Why Moodia?

AI is showing up in nearly everything, which makes it important to learn how to use it to build up creativity and emotion rather than replace them. Moodia does this by helping people fuel their moods and interests, matching what they watch to how they feel.

## How it works

1. You describe your mood or what you're in the mood for, and your preferred age rating.
2. Moodia uses an AI language model to understand how you feel.
3. It recommends movies that fit that mood, with a short description of the movie.

## Built with

- Python
- Gradio (chat interface)
- OpenAI API (language model)
- Hugging Face Spaces (hosting)
- Replit (front-end integration)
